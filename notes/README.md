# Engineering Notes

Standalone TI-Nspire CX Lua quick-reference app for ECE 216 and ECE 250.

## Source

`notes/main.lua`

## Build / transfer

Compile `notes/main.lua` into its own TI-Nspire Lua `.tns` document using the same Lua-to-TNS workflow used for the Engineering Toolbox. Name the resulting document `Engineering_Notes.tns`, then transfer it with TI-Nspire Computer Link.

This file is intentionally separate from the calculator toolbox.

## Navigation

- Up/Down: select categories/topics or scroll a note
- Enter: open category/topic
- Esc: go back
- Left/Right while reading: previous/next topic

## v1 topics

### ECE 250 - Circuits
KCL/KVL, nodal analysis, supernodes, mesh analysis, supermeshes, dependent sources, Thevenin/Norton, source transformations, capacitors/inductors, first-order RC/RL, second-order RLC, AC/phasors, and AC power.

### ECE 216 - Signals
Complex numbers, signal basics, LTI systems, convolution, sinusoids, and exponentials.

### Quick Math
Trig identities, derivatives, integrals, and SI prefixes.
